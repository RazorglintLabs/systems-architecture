# IP, Licensing, Commercial and Delivery Boundaries
**October 2026 · Public-facing non-confidential summary; not an offer or valuation**

| Asset class | Current posture | Critical boundary |
| --- | --- | --- |
| **Prestige-Reforged** | Proprietary retained core IP; staged technical development and human-first product work | Not included by default in any other system's outright sale; bounded adapter, license or OEM needs a separate agreement |
| **Compliance Drift Detector** | Public proprietary technical-preview source; qualified unsigned native Windows evaluator | Public GitHub visibility **does not grant open-source or redistribution rights**; final published artifacts/entitlements have separate gates |
| **Viventia** | Private local-first evidence/IR cockpit | Do not misrepresent SIEM/EDR, managed monitoring or unsupported customer deployment scale |
| **SAR and governed automation** | Private independent assets and potential bundle components | Source identity, dependencies, third-party rights and cross-component qualification required before transfer |
| **GCA Stack** | Phase 0 source/admission process | Candidate architectural components do not equal an integrated, buyer-accepted product |
| **Command Guardian** | Separate hardened prototype with historical MIT grant | Previously granted MIT rights cannot simply be revoked to make exclusive IP claims |
| **Local components/demos** | Mixed maturity and source locations | No transfer-ready package assumed until current IP and build audit |

## Before any sale, license or production assertion

1. Identify exact canonical source and repo/commit.
2. Verify TCOG/Razorglint ownership and upstream/donor lineage.
3. Inventory open-source software, models, data, rights and obligations.
4. Reproduce build and tests with exact environment and failures/skips.
5. Identify independent verification, input-truth and signing limitations.
6. Verify absence of secrets, customer data and private keys.
7. Spell out included and **excluded** assets, source, brand and future IP.
8. Bound support and any exclusivity; avoid invented customer/ROI/valuation claims.
